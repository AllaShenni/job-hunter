# Бот-парсер вакансий

Сам ищет удалённые вакансии куратора, модератора вебинаров и специалиста по сопровождению обучения и присылает подборку в Telegram.

## Как работает

- Запускается дважды в день, в 07:00 и 15:00 по Москве, через GitHub Actions.
- Ищет на hh.ru, в Telegram-каналах с вакансиями и на SuperJob (если задан ключ API).
- Отсеивает вакансии, где в основном продажи, преподавание или обязательные звонки.
- Не присылает одну вакансию дважды: отправленные хранятся в базе SQLite.

## Стек

Python 3.11, httpx, Telethon, Telegram Bot API, SQLite, GitHub Actions.

Сделан в Claude Code через вайбкодинг.

## Настройка

Ключи хранятся в GitHub Secrets, список нужных переменных в файле `.env.example`.

Проверки: `pytest`
